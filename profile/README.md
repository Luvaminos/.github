# Luvaminos

Luvaminos LLC is a US supplier of research-use-only peptides, based in Albuquerque, New Mexico.

## Lot transparency

- Every peptide lot is tested by one independent third-party lab, Freedom Diagnostics Testing, PLLC (Franklin, Tennessee). The lab is not owned by or affiliated with Luvaminos.
- Three results per lot: identity by mass spectrometry (LC-MS), purity by HPLC, and net content in milligrams against the label.
- Each certificate carries the lab's accession number. Search it on the lab's own site; the lab's copy should match ours, and if they differ, the lab's copy is right.
